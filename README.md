# Sistema de Gestão de Calendários Acadêmicos

Sistema web institucional desenvolvido para facilitar o gerenciamento de calendários acadêmicos, permitindo o controle de datas letivas, feriados, recessos, prazos e fluxo de solicitações de alteração entre as unidades acadêmicas e a administração central.

## Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end (Planejado):** Node.js & Express
- **Controle de Versão:** Git & GitHub

## Funcionalidades Principais
- **Perfil Master:** Gerenciamento do Calendário Base institucional, aprovação/recusa de solicitações das unidades e cadastro de novas unidades com opção de clonagem de dados.
- **Perfil Unidade Acadêmica:** Visualização dos calendários e envio de solicitações auditadas para alteração de dias travados.
- **Múltiplos Eventos por Dia:** Capacidade de adicionar vários eventos em um mesmo dia letivo de forma dinâmica.
- **Auditoria por Sessão:** Identificação institucional obrigatória na primeira tentativa de modificação do calendário da unidade.
- **Visualização Geral do Ano:** Layout otimizado em grade anual (2027 a 2030) para fácil consulta.
